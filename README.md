# OBJECTIF TRACTION

PWA indépendante d'entraînement psychotechnique CRL.

## Publication sur GitHub Pages
1. Créer un dépôt public nommé `objectif-traction`.
2. Ajouter à la racine les quatre fichiers : `index.html`, `manifest.json`, `sw.js`, `icon.svg`.
3. Dans Settings > Pages, choisir `Deploy from a branch`, branche `main`, dossier `/ (root)`, puis Save.
4. Attendre la publication. L'adresse sera de la forme `https://TON-PSEUDO.github.io/objectif-traction/`.

Les scores sont stockés localement dans le navigateur (`localStorage`) et ne sont pas partagés entre appareils.

## Important
Prototype pédagogique indépendant, non officiel et non affilié à la SNCF. Les mécanismes, consignes, niveaux et barèmes sont simplifiés et doivent être affinés à partir des consignes réellement communiquées au candidat.
